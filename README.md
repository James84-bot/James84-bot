In use at the Unity Homes estates. **[Try the live demo](https://james84-bot.github.io/ocf/?demo)**

**[Kenyans Are Asking](https://github.com/James84-bot/juakesho)**: a news channel on Instagram and Facebook run by a
Python pipeline on GitHub Actions. It drafts and checks posts, renders them to images and Reels, and publishes
only after I approve each one on Telegram. **[Brand book](https://james84-bot.github.io/juakesho/brand-book/)**

**Sales automations** (internal, for Unity Homes): n8n flows that match property enquiries to listings, reply by
email, score each lead and assign an agent in Slack.
